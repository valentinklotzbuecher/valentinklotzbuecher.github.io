Reproducible Research Pipelines with R and Quarto

Master’s seminar · University of Freiburg · Winter term 2024/25

One text file and one command, and out comes a web page, a PDF, a set of slides or a whole paper. Scroll on to see how.

A report starts as one plain text file: a few settings, then text, then code.

The settings say what to make. Here, a web page.

Numbers in the text are computed, not typed. Change the data and they change with it.

The code that draws a figure sits where the figure will appear.

Run quarto render and the file becomes a web page, with numbered tables and figures and links between them.

Change html to pdf. Same file, now a PDF.

Or to revealjs, for slides that run in any browser.

Figures can be maps.

When the project grows, the same pieces make a paper or a thesis, with equations, citations and a bibliography.

report.qmd
---
title: "Migration in numbers"
format: html
---

The data cover `r n_countries` countries.

```{r}
#| label: fig-births
#| fig-cap: "Birth rates by decade"
ggplot(countries, aes(birth_rate)) +
  geom_histogram() +
  facet_wrap(~decade)
```

@fig-births shows how they are spread.
